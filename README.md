# HR Analytics — Employee Attrition Dashboard

## Overview
Built an interactive Excel dashboard to analyse employee attrition patterns 
across 1,470 employees at a simulated corporation. Identified the top 3 risk 
factors driving 16% annual attrition and modelled retention recommendations 
for HR leadership.

## Problem Statement
- Company experiencing 16.12% annual attrition (~237 employees/year)
- HR team had no visual way to identify which departments or demographics 
  were highest-risk
- No data-driven recommendations existed for retention strategy

## Tools Used
| Tool | Purpose |
|------|---------|
| Microsoft Excel | Data cleaning, analysis, dashboard design |
| PivotTables | Interactive cross-tab analysis |
| Power Query | Data transformation and cleaning |
| Excel Charts | Visual communication of findings |

## Dataset
IBM HR Analytics Employee Attrition — Kaggle (CC0 Public Domain)
1,470 employee records | 35 variables | Link: [Kaggle Dataset](https://kaggle.com)

## Key Findings
- Sales Representatives have 2.5× higher attrition than the company average (39.8% vs 16.1%)
- Employees with a Job Satisfaction score of 1 leave at 4× the rate of score-4 employees
- 0–1 year tenure employees account for 40% of all voluntary departures
- Overtime workers have a 31% attrition rate vs 10% for non-overtime employees

## Recommendations
1. Implement structured stay interviews for employees in their first year
2. Review compensation and workload for Sales Representatives
3. Create a Job Satisfaction early-warning dashboard for managers
4. Establish an overtime policy review for high-attrition departments
